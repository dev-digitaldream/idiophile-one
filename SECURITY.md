# Security

Idiophile One reads local files, talks to radio-browser.info for the radio directory, plays
network streams and browses DLNA / UPnP servers on your network. It sends no telemetry and has
no account.

If you find a security problem (for example a malformed file or stream, or a hostile UPnP
device, that leads to code execution or file access outside your music), please do **not** open
a public issue. Use GitHub's [private vulnerability reporting](https://github.com/dev-digitaldream/idiophile-one/security/advisories/new).

Releases are published only on this repository's Releases page, with SHA-256 checksums.
